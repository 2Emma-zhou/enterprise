Tier0 adopts AI agent inside the UNS module, enabling you to interact with the UNS models simply by talking to the agent in natural language.
:::caution
Before starting a conversation with the agent, you need to set the API key for the agent in <img width={20} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/18.png" /> > **Settings** > **AI Settings**.
Otherwise the agent will not be able to respond to your instructions.
:::

1. Log in to Tier0, in **UNS**, select the **Agent** tab.

<img width={550} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/38.png" />

2. In the chat window on the right, drag a topic from the left side and drop it into the input box or directly @ and select a topic for data reference, and then enter your instructions.
3. Drag the cards generated based on your instructions to the canvas, and you can see the visualized data.

<img width={550} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/106.png" />

:::tip
- Click <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/107.png" /> at the lower-left corner of the conversation message to send the last instruction again.
- Click **Card List** at the top to see all the generated cards in the current session.
- Click <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/108.png" /> at the upper-right corner to start a new session.
:::
4. (optional) Click <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/110.png" /> at the upper-right corner of the card to add it to the chat or delete it.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/109.png" />

:::tip[What does the agent support?]
The UNS agent can take over the following tasks:
- Generate data models based on your instructions.
- Generate data flows based on your instructions, including **Source Flow** for data connection and **Event Flow** for data processing.
:::
