Tier0 Cloud provides App Builder for you to build industrial applications through no code writing yourself, and export them to local Tier0 Enterprise.

## Importing Apps

:::note[Get the app package first]
In Tier0 Cloud, export the bundle of the application you built. For details, see [Exporting Apps](https://docs.tier0.app/using-tier0/building-apps/#export-to-external).
:::

1. In Tier0 Enterprise, go to **App** > **Projects** and click **Create Project**.
2. Enter project name and click **Save**.
3. Inside the project, click **Import App** and select the app package you exported from Tier0 Cloud.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/10.png" />

4. Check the application information and then click **Import**.

## Configuring App
1. Inside the project, go to the **Members** tab.
2. Add members to the project and assign them roles so they can access the application within the granted permission scope.
:::note[Roles]
- Roles are created during application development in Tier0 Cloud. For details, see [Roles](https://docs.tier0.app/using-tier0/building-apps/#access-control).
- Roles are listed under the **Roles** tab in the project.
:::

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/11.png" />

## Accessing App
1. Go to **App** > **Launchpad** and select the project.
2. Click the application you want to access.
