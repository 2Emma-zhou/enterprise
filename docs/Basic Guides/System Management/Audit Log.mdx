Tier0 provides an audit log to track all operations performed by users.

## Viewing Audit Logs
1. Log in to Tier0, and select **System** > **Audit Log**.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/8.png" />

2. Enter the operator name at the upper-right corner to filter the audit logs.
