

## User
In this section, you can change the user profile, system language and reset the password.

### Changing User Profile
1. In Tier0, click the user icon at the upper-right corner, and then click **Profile**.
2. Click **Edit** to change the user profile, including the display name, email address and phone number.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/27.png" />

3. Click**Save**.

### Changing Preferences
1. In Tier0, click the user icon at the upper-right corner, and then click **Preferences**.
2. Change the system language between English and Chinese.
3. Change the homepage of Tier0 as needed.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/28.png" />

### Changing Password
1. In Tier0, click the user icon at the upper-right corner, and then click **Security**.
2. Click **Reset Password**, enter corresponding passwords and click **OK**.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/29.png" />

3. (optional) Click **Sign Out** to directly sign out.

## Service
### Setting API Key
:::info
API key is necessary for API and CLI access.
:::
1. In Tier0, click the user icon at the upper-right corner, and then click **API Key**.
2. Click **New Key**, and set the key type and permisson.
- **Service Key**: Created by admin, all permissions are available.
- **Personal Key**: Created by operators, and only **Read-only** permission.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/30.png" />

3. Click **OK**.
:::tip
Check the guide on the bottom to understand the way of using API and CLI to access the platform with the help of the API key.
:::

### Setting AI API Key
:::caution
This is necessary for using the UNS agent.
:::
1. In Tier0, click the user icon at the upper-right corner, and then click **AI Settings**.
2. Enter the necessary information of your AI model.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/31.png" />

:::tip[If you need to switch provider]
Click <img width={20} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/32.png" /> at the upper-right corner to change the model provider.
:::

3. Click **Save Settings**.

## Platform
### System Configuration
You can complete the following tasks on this page:
- **Login**: Change the time period where the account stays signed in.
- **License**
    - Change the Tier0 license type by editing the license key you get from the vendor.
    - View license status, expiration date and binding ID.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/33.png" />

### Managing Users
In Tier0, click the user icon at the upper-right corner, and then click **User Management**.
#### Adding User
1. Click **New User** at the upper-right corner on the **Users** tab.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/34.png" />

2. Enter the information and select a role for the user, and then click **Save**.

- You can disable, edit, delete user and reset password of users.
- The default user cannot be disabled or deleted.

#### Adding User Group
1. Click **New User Group** at the upper-right corner on the **User Group** tab.
2. Enter the information, and then click **Save**.
3. Click the group, and then click **Add Members** to add users to the group.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/35.png" />

4. Click **Add Selected Users**.

### Adding OAuth Client
This function is unavailable presently.

### Viewing Logs
- Check detailed operation logs in **Audit Log**.
- View login logs in **Login Log**.

### Setting Notifications
You can create notifications and send them to different recipients.
1. In Tier0, click the user icon at the upper-right corner, and then click **System Message Management**.
2. Click **Create notification**, enter the message title and content, and set the delivery information.

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/36.png" />

3. Send the notification.
