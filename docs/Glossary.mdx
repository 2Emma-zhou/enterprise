<table>
        <caption>Key Terms and Definitions</caption>
        <thead>
            <tr>
                <th>Term</th>
                <th>Definition</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>Tier0</td>
                <td>An open-source industrial data integration platform built on the Unified Namespace (UNS) methodology, designed for managing, processing, and optimizing industrial data.</td>
            </tr>
            <tr>
                <td>UNS (Unified Namespace)</td>
                <td>A data management method that centralizes data from various devices and systems, providing a structured and unified framework to prevent data silos.</td>
            </tr>
            <tr>
                <td>Node-RED</td>
                <td>An open-source automation tool that enables users to wire together devices, APIs, and online services using a flow-based programming approach.</td>
            </tr>
            <tr>
                <td>MQTT</td>
                <td>A lightweight messaging protocol for small sensors and mobile devices optimized for high-latency or unreliable networks, commonly used for IoT communication.</td>
            </tr>
            <tr>
                <td>JSON</td>
                <td>JavaScript Object Notation, a lightweight data-interchange format that is easy for humans to read and write and easy for machines to parse and generate.</td>
            </tr>
            <tr>
                <td>TimescaleDB</td>
                <td>An open-source time-series database built on PostgreSQL, designed for handling large-scale time-series data, especially useful for monitoring systems and IoT applications.</td>
            </tr>
            <tr>
                <td>PostgreSQL</td>
                <td>An advanced open-source relational database management system that uses SQL for querying and is designed for high performance and reliability.</td>
            </tr>
            <tr>
                <td>API (Application Programming Interface)</td>
                <td>A set of protocols and tools that allows different software applications to communicate and interact with each other.</td>
            </tr>
            <tr>
                <td>Topic</td>
                <td>A unique identifier for data in the Tier0 system that helps classify and organize data from various sources for easy access and management.</td>
            </tr>
            <tr>
                <td>REST API</td>
                <td>A web service interface that allows applications to communicate over HTTP, using standard methods like GET, POST, PUT, and DELETE to access resources.</td>
            </tr>
            <tr>
                <td>Time-Series Data</td>
                <td>Data that is collected and recorded at regular intervals over time, such as equipment run time, temperature, and other performance metrics.</td>
            </tr>
            <tr>
                <td>JSON Payload</td>
                <td>Data transferred in the form of a JSON object that contains relevant information, such as sensor readings or device states, to be processed or stored.</td>
            </tr>
            <tr>
                <td>Authentication</td>
                <td>The process of verifying the identity of a user or system to ensure that only authorized entities can access resources.</td>
            </tr>
            <tr>
                <td>Event-Driven</td>
                <td>A programming paradigm in which the flow of the program is determined by events, such as user actions, sensor data, or messages from other systems.</td>
            </tr>
            <tr>
                <td>Digital Twin</td>
                <td>A digital representation of a physical object, process, or system that uses data to reflect its state and behavior for monitoring, analysis, or simulation.</td>
            </tr>
            <tr>
                <td>AI Agent</td>
                <td>A software system that uses artificial intelligence to interpret goals, make decisions, and take actions, often by using tools or interacting with other systems.</td>
            </tr>
            <tr>
                <td>Marimo Notebook</td>
                <td>An interactive Python notebook built with marimo, where cells react to changes in their dependencies to keep results up to date.</td>
            </tr>
            <tr>
                <td>API Key</td>
                <td>A credential used to identify and authenticate an application or caller when accessing an API.</td>
            </tr>
            <tr>
                <td>OAuth</td>
                <td>An authorization framework that lets an application obtain limited access to a user's resources without sharing the user's password with that application.</td>
            </tr>
            <tr>
                <td>Visual Algorithm</td>
                <td>An image or video processing algorithm that analyzes visual data to detect, recognize, measure, or classify objects and patterns.</td>
            </tr>
            <tr>
    <td>JSONB</td>
    <td>A PostgreSQL data type that stores JSON data in a binary format, offering efficient indexing, faster querying, and improved performance compared to plain JSON fields.</td>
</tr>
        </tbody>
    </table>
