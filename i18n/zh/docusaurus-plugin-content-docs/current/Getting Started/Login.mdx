1. 在浏览器中使用部署好的域名和端口访问 Tier0。
2. 在登录页面，使用许可证激活 Tier0。

- **在线激活**：输入许可证密钥，然后单击 **立即激活**。

<img width={750} src="http://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/1-1.png" />

- **离线激活**：将设备标识发送给供应商以获取 JSON 文件，然后导入该文件。

<img width={750} src="http://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/2-1.png" />

3. 激活后，输入默认用户名和密码（tier0/tier0）。

4. 单击 **登录**。
