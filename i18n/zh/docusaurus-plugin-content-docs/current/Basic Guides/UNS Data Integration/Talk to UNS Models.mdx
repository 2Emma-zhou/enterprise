Tier0 在 UNS 模块中内置了 AI Agent，你可以直接使用自然语言与 UNS 模型进行交互。
:::caution
在与 Agent 对话前，你需要在 <img width={20} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/18.png" /> > **设置** > **AI 设置** 中设置智能体的 API Key，否则 Agent 将无法响应你的指令。
:::

## 如何使用 UNS Agent

1. 登录 Tier0，在 **数据建模** 内，选择 **Agent** 页签。

<img width={550} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/38-1.png" />

2. 在右侧聊天窗口中，将左侧的文件拖拽到输入框中或输入@选择文件完成数据引用，然后输入指令。
3. 将根据指令生成的卡片拖拽到画布中，即可查看可视化数据。

<img width={550} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/106-1.png" />

:::tip
- 单击对话消息左下角的 <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/107.png" />，可以重新发送上一条指令。
- 单击顶部的 **卡片列表**，可以查看当前会话中生成的所有卡片。
- 单击右上角的 <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/108.png" />，可以开始新的会话。
:::

4. （可选）单击卡片右上角的 <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/110.png" />，可以将卡片添加到聊天中或删除卡片。

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/109-1.png" />

:::tip[Agent 可以做什么？]
UNS Agent 可以根据你的指令：
- 生成数据模型。
- 生成用于连接数据的**数据连接**流程，以及用于处理数据的**事件流程**。
:::
