1. 登录 Tier0，然后选择 **流程**。

<img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/23-1.png" />

<table>
  <thead>
    <tr>
      <th>编号</th>
      <th>项目</th>
      <th>说明</th>
    </tr>
  </thead>
  <tbody>
  <tr>
      <td>1</td>
      <td>数据流列表</td>
      <td>选择查看全部数据流，或仅查看某一分类下的流。</td>
    </tr>
    <tr>
      <td>2</td>
      <td>数据流信息</td>
      <td>显示数据流基础信息。单击流名称可开始编辑数据流。</td>
    </tr>
  <tr>
      <td rowspan="3">3</td>
      <td>搜索/筛选</td>
      <td>搜索或筛选已有数据流。</td>
    </tr>
    <tr>
      <td>新建文件夹</td>
      <td>添加文件夹，用于对数据流进行分类。</td>
    </tr>
    <tr>
      <td>新建流程</td>
      <td>添加新的数据流。</td>
    </tr>
  </tbody>
</table>

2. 单击 **新建流程**，输入名称和说明，将 **流程类型** 选择为 **事件流程**，然后单击 **保存**。

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/26-1.png" />

3. 单击刚添加的流程，构建数据事件以处理数据。
