先完成图中的两个必做步骤：

<img width={650} src="/img/user-journey-zh.svg" alt="先构建数据模型，再连接数据；随后按需处理、同步、使用或分析数据" />

- **必做**
    1. **构建数据模型**，组织资产并确定数据的归属位置。
    2. **连接数据**，将数据源中的数据接入模型。

- **可选**
    - **处理数据**，通过**事件流程**转换和准备数据。
    - **同步数据**，与其他 Tier0 同步数据，或通过 OpenAPI 和 MQTT 对外提供数据。
    - **使用数据**，将数据用于应用和业务场景。
    - **分析数据**，探索并可视化数据，从中获得洞察。
