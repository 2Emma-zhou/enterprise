## 如何创建数据模型
基于简单的路径和主题结构，可将数据层级定义为树形视图。

### 手动创建模型

1. 登录 Tier0，选择**统一命名空间** > **UNS**。
2. 单击 <img src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/75.png" /> > **新建路径**，添加路径（例如 `factory`）。

<img width={450} src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/34-1.png" />

3. 填写路径信息，按需设置别名，然后单击**保存**。
4. 选中 **factory**，单击 <img src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/75.png" /> > **新建主题**，在其下添加主题（例如 `CNC`）。

<img width={450} src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/36-1.png" />

5. 填写主题信息，然后单击**保存**。

### 导入模型
1. 登录 Tier0，进入 **UNS** 页面。
2. 单击右上角的**导入**。
3. 导入 JSON 创建模型：
- 在 **UNS** 选项卡中直接输入 JSON。

:::tip[如何快速获取模型 JSON]
单击**复制给 Agent**，将复制的内容发送给智能体，再将其生成的结果粘贴回来。
:::

<img width={350} src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/69-5.png" />

- 在 **UNS** 选项卡中单击**下载模板**，填写模型内容后，在**全部**选项卡上传文件。

<img width={450} src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/69-2.png" />

:::tip
也可以手动添加路径和主题，再将其导出，作为导入模型的示例。

<img width={450} src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/69-6.png" />

:::

4. 单击**保存**。

### 导出数据
Tier0 支持导出 UNS 模型及其他数据，例如数据连接、事件流程和数据看板。
1. 在 **UNS** 页面，单击右上角的**导出**。
2. 单击**其他**选项卡，选择对应的数据类型。

<img width={450} src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/190.png" />

3. 单击**导出**。
