## 如何构建数字孪生场景

1. 登录 Tier0，选择 **Anchor** > **场景**。
2. 单击右上角的 **新建场景**，输入场景信息，然后单击 **创建**。

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/90-1.png" />

3. 打开已创建的场景，从左侧 **实例库** 中选择实例。

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/91-1.png" />

4. 配置添加到场景中的模型。
    1. 设置模型坐标。
    2. 基于所选坐标调整模型的位置、旋转和缩放。
    3. 在右侧根据需要编辑视口、相机和网格。
    4. 编辑光照设置。
    5. 可选：通过设置 **对象** > **变换** 下的数值来编辑模型位置。

5. 单击右上角的 **保存场景**。
