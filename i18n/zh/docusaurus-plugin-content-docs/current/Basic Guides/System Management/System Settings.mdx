## 用户

在此处，你可以修改个人资料、系统语言和密码。

### 修改个人资料

1. 在 Tier0 中，点击右上角的用户图标，然后点击 **个人资料**。
2. 点击 **编辑**，修改显示名称、邮箱地址和电话号码等个人资料。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/27-1.png" />

3. 点击 **保存**。

### 修改偏好设置

1. 在 Tier0 中，点击右上角的用户图标，然后点击 **偏好设置**。
2. 将系统语言切换为中文或英文。
3. 根据需要更改 Tier0 首页。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/28-1.png" />

### 修改密码

1. 在 Tier0 中，点击右上角的用户图标，然后点击 **安全设置**。
2. 点击 **重置密码**，输入所需密码，然后点击 **确定**。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/29-1.png" />

3. （可选）点击 **退出登录**，直接退出当前账号。

## 服务

### 设置 API 密钥

:::info
通过 API 和 CLI 访问平台时，需要使用 API 密钥。
:::

1. 在 Tier0 中，点击右上角的用户图标，然后点击 **API 密钥**。
2. 点击 **新建密钥**，设置密钥类型和权限。
   - **服务密钥**：由管理员创建，拥有全部权限。
   - **个人密钥**：由操作员创建，仅有**只读**权限。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/30-1.png" />

3. 点击 **确定**。

:::tip
参考页面底部的指南，了解如何使用 API 密钥通过 API 和 CLI 访问平台。
:::

### 设置 AI API 密钥

:::caution
使用 UNS 智能体前，需要完成此设置。
:::

1. 在 Tier0 中，点击右上角的用户图标，然后点击 **AI 设置**。
2. 填写 AI 模型所需的信息。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/31-1.png" />

:::tip[如需切换服务提供商]
点击右上角的 <img width={20} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/32.png" />，切换模型服务提供商。
:::

3. 点击 **保存设置**。

## 平台

### 系统配置

你可以在此页面完成以下操作：

- **登录**：修改账号保持登录状态的时长。
- **许可证**：
  - 编辑从供应商处获取的许可证密钥，更改 Tier0 许可证类型。
  - 查看许可证状态、到期日期和绑定 ID。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/33-1.png" />

### 管理用户

在 Tier0 中，点击右上角的用户图标，然后点击 **用户管理**。

#### 新增用户

1. 在 **用户** 页签右上角，点击 **新建用户**。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/34-1.png" />

2. 填写用户信息并选择角色，然后点击 **保存**。

- 你可以禁用、编辑、删除用户，以及重置用户密码。
- 默认用户无法禁用或删除。

#### 新增用户组

1. 在 **用户组** 页签右上角，点击 **新建用户组**。
2. 填写信息，然后点击 **保存**。
3. 点击该用户组，然后点击 **添加成员**，将用户加入组中。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/35-1.png" />

4. 点击 **添加选中的用户**。

### 添加 OAuth 客户端

此功能目前不可用。

### 查看日志

- 在 **审计日志** 中查看详细的操作日志。
- 在 **登录日志** 中查看登录记录。

### 设置通知

你可以创建通知，并发送给不同的接收对象。

1. 在 Tier0 中，点击右上角的用户图标，然后点击 **系统消息管理**。
2. 点击 **创建通知**，输入消息标题和内容，并设置发送信息。

<img width={450} src="https://enterpriseimage.oss-cn-hangzhou.aliyuncs.com/36-1.png" />

3. 发送通知。
